OBS에 연결하기

  1. 대시보드에서 오버레이를 엽니다.

    대시보드 → 채팅 오버레이로 이동하고 채팅 또는 타이머 탭을 선택하세요.

  2. 디자인을 확인하고 적용합니다.

    원하는 옵션을 설정한 뒤 적용을 눌러 저장하세요. 미리보기로 표시 상태를 확인할 수 있습니다.

  3. 복사한 링크를 OBS에 등록합니다.

    OBS의 소스 목록에서 브라우저를 추가하고, 선택한 오버레이의 OBS 링크를 URL에 넣으세요. 소스 크기와 위치는 방송 화면에 맞게 조정하세요.

채팅과 타이머는 각각의 OBS 링크를 사용합니다. 그림 도네이션 오버레이는 그림 도네이션 가이드에서 안내합니다.

채팅 오버레이

대시보드에서 OBS 브라우저 소스용 채팅 오버레이 링크를 만들고, 방송 화면에 표시될 채팅창 디자인을 직접 조정할 수 있습니다.

대시보드 > 채팅 오버레이
글자 크기, 채팅창 폭, 여백, 말풍선 모양, 색상, 애니메이션, 메시지 유지시간을 옵션으로 설정할 수 있습니다. CSS를 몰라도 기본 옵션만으로 바로 사용할 수 있으며, 설정 후 적용을 누르면 미리보기와 실제 오버레이에 반영됩니다.
미리보기와 OBS 링크
샘플 모드에서는 닉네임과 채팅 내용을 직접 입력해 디자인을 확인할 수 있습니다. 현재 채팅 모드에서는 실제 채팅 표시 상태를 확인할 수 있으며, 복사한 오버레이 링크를 OBS의 브라우저 소스 URL에 넣으면 방송 화면에 채팅이 표시됩니다.
프리셋과 고급 CSS
마음에 드는 설정은 프리셋으로 저장하고 다시 불러올 수 있습니다. 이미지 스킨이나 세부 디자인을 직접 다듬고 싶다면 고급 CSS 모드를 사용할 수 있습니다. 스킨이 없어도 기본 CSS로 정상 동작합니다.
스킨용 주요 클래스:
.chat-frame: 채팅창 프레임/배경 이미지
.chat-list: 메시지 영역 여백/클리핑
.chat-message: 말풍선 이미지와 개별 메시지
.chat-name, .chat-text: 닉네임과 채팅 본문
필터와 링크 관리
특정 닉네임을 오버레이에서 숨기거나, 스트리머/관리자 역할의 채팅을 필터링할 수 있습니다. 오버레이 링크는 채널 기준 고정 주소이므로 OBS에 한 번 등록하면 계속 사용할 수 있습니다.

타이머 오버레이

오버레이 편집기의 타이머 탭에서 글자 크기, 색상, 투명도와 완료 후 표시 동작을 설정할 수 있습니다. 타이머 링크를 OBS에 등록한 뒤 스트리머 또는 매니저가 채팅 명령어로 제어합니다.

!타이머 [시간] / !타이머 [제목] [시간] 관리자용
!타이머 10 → 10분 타이머
!타이머 쉬는 시간 01:30 → 제목이 있는 1분 30초 타이머
시간은 10분, 90초, 01:30, 1:00:00 형식으로도 입력할 수 있습니다.
명령어동작
!타이머 재생정지한 타이머를 이어서 재생합니다. 완료된 타이머는 처음부터 재생합니다.
!타이머 정지남은 시간을 유지하며 타이머를 일시 정지합니다.
!타이머 삭제현재 타이머를 화면에서 제거합니다.
설정의 자동 시작을 끄면 생성한 타이머는 대기 상태로 표시됩니다. !타이머 재생으로 시작하세요. 명령어 접두사를 바꿨다면 ! 대신 설정한 접두사를 사용합니다.
